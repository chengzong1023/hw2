# 🗺️ 地圖使用說明

## 問題說明
您在IDE中看到的是HTML原始碼，這是正常的！HTML檔案需要在**瀏覽器中執行**才能顯示地圖。

## 🔍 正確的查看方式

### 方法1：直接在瀏覽器中開啟
1. **找到檔案**：`c:\Users\admin\Desktop\遙測\script\exercise2\guaranteed_map.html`
2. **右鍵點擊**該檔案
3. **選擇「開啟方式」**
4. **選擇瀏覽器**（Chrome、Firefox、Edge等）
5. **地圖應該會顯示**：台灣地圖 + 彩色標記

1. **開啟瀏覽器**（Chrome、Firefox、Edge）
2. **直接拖拽HTML檔案**到瀏覽器視窗
3. **釋放滑鼠**，地圖會自動載入

### 方法3：從瀏覽器選擇檔案
1. **開啟瀏覽器**
2. **按Ctrl+O**（開啟檔案）
3. **選擇HTML檔案**
4. **點擊開啟**

## 🚨 如果仍然無法顯示

### 檢查步驟：
1. **確認檔案副檔名**：必須是 `.html`
2. **檢查瀏覽器控制台**：
   - 按 **F12** 開啟開發者工具
   - 點擊 **Console** 標籤
   - 查看是否有錯誤訊息
3. **檢查網路連線**：需要載入地圖瓦片

### 常見問題：
- **空白頁面**：可能是網路問題，無法載入地圖瓦片
- **只有程式碼**：表示檔案沒有在瀏覽器中執行
- **JavaScript錯誤**：控制台會顯示具體錯誤
