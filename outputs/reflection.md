# Data Integrity: 資料完整性分析

### 原始資料發現的問題
在分析政府開放資料平台的避難收容處所資料時，我發現了幾個關鍵的資料完整性問題：

1. **坐標異常值**：原始5,973筆資料中發現109個異常坐標，包括超出台灣地理邊界、坐標為(0,0)、以及可能在海洋中的位置。這些異常值可能來自於資料輸入錯誤、坐標系統混用，或是設備定位誤差。

2. **缺乏室內/室外標記**：雖然資料中有「室內」和「室外」欄位，但大多數記錄為空值或標記不一致。這使得無法直接判斷避難所的類型，對於空氣品質風險評估造成困難。

3. **坐標系統不統一**：部分資料可能混用不同的坐標系統（WGS84 vs TWD97），需要進行坐標系統驗證和轉換。

4. **資料更新頻率不明**：無法確定資料的最新更新時間，可能存在已不存在的避難所仍被列在資料中。

### 處理缺乏「室內/室外」屬性的困境
為了解決缺乏室內/室外標記的問題，我採用了多層次的AI推斷方法：

1. **關鍵字分類**：建立強、中、弱三級關鍵字庫，根據設施名稱推斷類型。例如「活動中心」、「學校」、「禮堂」歸類為室內；「公園」、「廣場」、「體育場」歸類為室外。

2. **信心度評估**：為每個推斷結果提供高、中、低三級信心度，便於後續人工審核。

3. **預設原則**：在無法確定時，預設為室內設施，採取保守的安全原則。

4. **原始資料優先**：優先使用原始資料中的室內/室外標記，只在缺失時才使用AI推斷。

這種方法雖然解決了標記缺失問題，但也承認可能存在分類錯誤的風險，特別是對於名稱模糊或功能複合的設施。

Cascade在台灣坐標系統（CRS）方面確實出現了一些「幻覺」：

1. **過度簡化假設**：最初假設所有坐標都是WGS84，沒有考慮台灣可能使用TWD97或TWD97_TM2的可能性。

2. **坐標差異誤解**：在分析第一週的氣象站資料時，Cascade最初認為兩組坐標間的差異是隨機誤差，但實際上這反映了TWD97和WGS84之間的系統性偏移。

3. **轉換工具選擇**：雖然最終正確使用了pyproj進行CRS轉換，但在初期建議了一些不適用的轉換方法。

4. **台灣地理知識**：對台灣的地理邊界和行政區劃有基本認識，但在精確的坐標驗證方面需要更多本地化知識。

這些「幻覺」主要源於缺乏台灣特定的地理資訊系統知識，但通過後續的學習和改進，Cascade能夠正確實作CRS轉換和驗證。

## Spatial Reasoning: 空間推理評估

### 「最近測站」作為評估指標的合理性
「最近測站」作為評估指標具有一定的合理性，但也存在明顯限制：

**合理性**：
1. **直觀易懂**：距離越近，空氣品質狀況越可能相似，符合一般人的直覺。
2. **計算簡便**：使用Haversine公式可以快速計算地球表面兩點間的直線距離.
3. **初步篩選**：可以快速識別需要關注的高風險區域.

**限制性**：
1. **忽略地形影響**：直線距離不考慮山脈、河谷等地形對空氣流動的影響.
2. **不考慮風向**：下風方向的空氣品質影響遠大於上風方向.
3. **人口密度忽略**：未考慮避難所服務人口密度和實際需求.
4. **交通可達性**：直線距離不等於實際可通行的距離.

### 主導開發者應考慮的其他變數
作為主導開發者，除了最近測站距離外，還應考慮以下重要變數：

1. **氣象因子**：
   - **風向風速**：主導風向決定污染物傳播方向和速度
   - **大氣穩定度**：影響污染物擴散條件
   - **溫度層結**：逆溫層會阻礙污染物擴散

2. **地理因子**：
   - **地形高度**：海拔高度影響污染物沉積
   - **海岸線距離**：海陸風影響空氣流動
   - **都市化程度**：熱島效應和建築物影響

3. **人口社會因子**：
   - **服務人口數**：避難所實際服務的人口規模
   - **脆弱族群比例**：老人、兒童、慢性病患比例
   - **交通便利性**：大眾運輸可達性

4. **設施特性**：
   - **通風條件**：建築物通風設計影響室內空氣品質
   - **濾淨設備**：是否具備空氣濾淨設備
   - **容量利用率**：實際使用率vs設計容量

5. **時間動態因子**：
   - **季節變化**：不同季節的氣象模式和污染源變化
   - **日變化**：日夜交替對大氣穩定度的影響
   - **事件影響**：特殊事件（如煙火、工業事故）的短期影響

考慮這些變數將大幅提升風險評估的準確性和實用性，使系統從簡單的距離分析進化為綜合的環境風險評估工具.

## 結論與學習

這次分析過程讓我深刻認識到空間資料分析的複雜性和挑戰。資料品質問題需要多層次的驗證方法，AI協作雖然強大但仍需人工監督和專業知識指導。空間推理不能僅依賴簡單的距離計算，必須考慮真實世界的複雜因素.

未來的改進方向包括建立更完善的風險評估模型、整合更多環境和社會因子、以及開發更智能的資料驗證機制。這些改進將使系統更具實用價值，能夠為災害防救和環境決策提供更可靠的支援.
